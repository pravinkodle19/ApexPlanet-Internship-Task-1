Basics of Web Development

Learn HTML, CSS and JavaScript

1. HTML

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of a webpage.

HTML Elements

HTML provides elements such as headings, paragraphs, images and links.

Learn more about HTML: Visit HTML Documentation

2. CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design webpages.

CSS Features

  • Colors
  • Fonts
  • Spacing
  • Layout
  • Backgrounds

3. JavaScript

What is JavaScript?

JavaScript is used to add interaction and dynamic behavior to webpages.
